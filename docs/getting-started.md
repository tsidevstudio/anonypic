# Getting Started with AnonyPic

AnonyPic provides on-device photo privacy tools for Android.

## Public privacy model

AnonyPic is designed around local processing and does not use analytics.

## Typical workflow

1. Choose or capture a supported image
2. Apply the available privacy tools
3. Review the result
4. Save or share only the version you intend to use

## Good practice

Always review the final image before sharing it.
