# AnonyPic Privacy Model

AnonyPic is designed for privacy-focused photo workflows.

## Public principles

- Processing is designed to happen on-device
- No analytics
- No unnecessary account requirement
- User review remains important before sharing processed images

## Publication boundary

This repository does not publish:

- Internal image-processing implementation
- Detection logic
- Model internals
- Source code
- Internal file-handling architecture
- Security-sensitive implementation details
